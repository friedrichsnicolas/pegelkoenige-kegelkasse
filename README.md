# Kegelkasse – Anrather Pegelkönige

Web-App für Strafen, Beiträge und Kasse des Kegelclubs.

- `index.html` + `config.js` + `sw.js` + `manifest.webmanifest`: installierbare Web-App (PWA). Firebase-Werte in `config.js` eintragen.
- `einzeldatei/index.html`: dieselbe App als eine einzelne Datei (für den Netlify-Import).
- `firestore.rules`: Sicherheitsregeln für die Firebase-Datenbank.
- `ANLEITUNG.md`: Einrichtung Schritt für Schritt.

Es liegen keine Vereinsdaten in diesem Repository. Die Daten stehen in der Firebase-Datenbank.
